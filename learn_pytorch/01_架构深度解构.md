## 1. Tokenizer 设计深度分析

### 1.1 BPE (Byte Pair Encoding) 算法原理

#### 数学定义
BPE 是一种基于统计的子词分词算法，通过迭代合并最频繁的字符对来构建词表。

**算法步骤**：
```
输入: 语料库 C, 目标词表大小 V
输出: 词表 V

1. 初始化词表为所有字符的集合
2. while |V| < target_size:
   a. 统计所有相邻字符对的频率
   b. 选择频率最高的字符对 (x, y)
   c. 合并为新符号 z = x + y
   d. 更新语料库：将所有 xy 替换为 z
   e. 将 z 加入词表 V
3. return V
```

#### Python 实现（简化版）

```python
from collections import defaultdict

class SimpleBPE:
    def __init__(self, num_merges=1000):
        self.num_merges = num_merges
        self.merges = []
        self.vocab = set()
    
    def get_stats(self, word_freqs):
        """统计相邻字符对的频率"""
        pairs = defaultdict(int)
        for word, freq in word_freqs.items():
            symbols = word.split()
            for i in range(len(symbols) - 1):
                pairs[(symbols[i], symbols[i + 1])] += freq
        return pairs
    
    def merge_vocab(self, word_freqs, pair):
        """合并指定的字符对"""
        new_word_freqs = {}
        bigram = ' '.join(pair)
        replacement = ''.join(pair)
        
        for word in word_freqs:
            new_word = word.replace(bigram, replacement)
            new_word_freqs[new_word] = word_freqs[word]
        
        return new_word_freqs
    
    def train(self, corpus):
        """训练 BPE 模型"""
        # 初始化：将每个词拆分为字符序列
        word_freqs = defaultdict(int)
        for word in corpus:
            # 在字符间添加空格，便于后续合并
            word_freqs[' '.join(word) + ' </w>'] += 1
        
        # 迭代合并
        for i in range(self.num_merges):
            pairs = self.get_stats(word_freqs)
            if not pairs:
                break
            
            # 选择频率最高的字符对
            best_pair = max(pairs, key=pairs.get)
            word_freqs = self.merge_vocab(word_freqs, best_pair)
            self.merges.append(best_pair)
            
            if i % 100 == 0:
                print(f"Merge {i}: {best_pair} (freq: {pairs[best_pair]})")
        
        # 构建最终词表
        self.vocab = set()
        for word in word_freqs:
            self.vocab.update(word.split())
        
        return self.vocab
    
    def encode(self, text):
        """编码文本"""
        # 将文本拆分为字符
        word = ' '.join(text) + ' </w>'
        
        # 应用所有合并规则
        for pair in self.merges:
            bigram = ' '.join(pair)
            replacement = ''.join(pair)
            word = word.replace(bigram, replacement)
        
        return word.split()
```

### 1.2 BPE vs Unigram 对比分析

#### Unigram Language Model

**核心思想**：基于概率的语言模型，通过最大化似然来选择最优的分词方式。

**算法步骤**：
```
1. 初始化一个大词表（如所有子串）
2. 计算每个 token 的概率（基于频率）
3. 对每个词，计算所有可能分词的概率
4. 移除对似然贡献最小的 token
5. 重复步骤 2-4 直到达到目标词表大小
```

#### 详细对比表

| 维度 | BPE | Unigram | 优势方 |
|------|-----|---------|--------|
| **算法复杂度** | O(V × N) | O(V² × N) | BPE |
| **词表构建** | 贪心合并 | 概率优化 | Unigram |
| **分词歧义** | 无（确定性） | 有（概率选择） | BPE |
| **训练速度** | 快 | 慢 | BPE |
| **词表质量** | 中 | 高 | Unigram |
| **实现复杂度** | 简单 | 复杂 | BPE |
| **可解释性** | 高 | 中 | BPE |
| **多语言支持** | 好 | 更好 | Unigram |

#### 数学推导：Unigram 的概率计算

给定句子 $S = s_1, s_2, ..., s_n$，分词结果为 $x = x_1, x_2, ..., x_m$：

$$P(x|S) = \frac{P(S|x)}{\sum_{x' \in \mathcal{X}(S)} P(S|x')}$$

其中：
- $\mathcal{X}(S)$ 是句子 $S$ 所有可能的分词方式
- $P(S|x) = \prod_{i=1}^{m} P(x_i)$ 是分词序列的概率

**损失函数**（对数似然）：
$$\mathcal{L} = \sum_{S \in \mathcal{D}} \log \left( \sum_{x \in \mathcal{X}(S)} \prod_{t \in x} P(t) \right)$$

struct BPE {
    vocab: HashSet<String>,
    merges: Vec<(String, String)>,

impl BPE {
    fn train(&mut self, corpus: &[String], num_merges: usize) {
        // 使用并行迭代器加速统计
        let pairs: HashMap<(String, String), usize> = corpus
            .par_iter()
            .flat_map(|word| {
                word.as_bytes()
                    .windows(2)
                    .map(|w| ((w[0] as char).to_string(), (w[1] as char).to_string()))
            })

                *acc.entry(pair).or_insert(0) += 1;
                acc
            })
            .reduce(|| HashMap::new(), |mut a, b| {
                for (k, v) in b {
                    *a.entry(k).or_insert(0) += v;
                }
                a
            });
        
        // 选择最频繁的字符对
        let best_pair = pairs
            .into_iter()
            .max_by_key(|(_, count)| *count)
            .map(|(pair, _)| pair);
        
        // ... 后续处理
    }
}

        self.merges = merges  # 合并规则
    
    def encode(self, text):

        # 1. 预处理：Unicode 规范化
        text = self._normalize(text)
        
        # 2. 预分词：按空格和标点分割
        words = self._pre_tokenize(text)
        
        # 3. BPE 编码

        for word in words:
            word_tokens = self._bpe_encode(word)
            tokens.extend(word_tokens)
        
        return tokens
    
    def _bpe_encode(self, word):
        """对单个词进行 BPE 编码"""
        # 将词拆分为字符
        word = list(word)
        
        # 应用合并规则
        while len(word) > 1:
            # 找到最早可以应用的合并规则
            pairs = [(word[i], word[i+1]) for i in range(len(word)-1)]
            
            # 选择优先级最高的合并规则
            best_pair = None
            best_rank = float('inf')
            for pair in pairs:
                if pair in self.merges:
                    rank = self.merges[pair]
                    if rank < best_rank:
                        best_rank = rank
                        best_pair = pair
            
            if best_pair is None:
                break
            
            # 应用合并
            new_word = []
            i = 0
            while i < len(word):
                if i < len(word) - 1 and word[i] == best_pair[0] and word[i+1] == best_pair[1]:
                    new_word.append(best_pair[0] + best_pair[1])
                    i += 2
                else:
                    new_word.append(word[i])
                    i += 1
            word = new_word
        
        return word

## 2. 模型架构数学推导

### 2.1 Transformer Decoder 架构总览

#### 整体架构图

```
输入 Token IDs
    ↓
Token Embedding (vocab_size, n_embd)
    ↓
位置编码 (RoPE)
    ↓
┌─────────────────────────────────┐
│  Transformer Block × n_layer    │
│  ┌───────────────────────────┐  │
│  │  RMSNorm                  │  │
│  │  ↓                        │  │
│  │  Causal Self-Attention    │  │
│  │  ↓                        │  │
│  │  Residual Connection      │  │
│  │  ↓                        │  │
│  │  RMSNorm                  │  │
│  │  ↓                        │  │
│  │  MLP (Feed Forward)       │  │
│  │  ↓                        │  │
│  │  Residual Connection      │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
    ↓
Final RMSNorm
    ↓
LM Head (n_embd, vocab_size)
    ↓
Logits (Softcap)
    ↓
输出概率分布
```

#### 参数量计算

**总参数量公式**：
$$P_{total} = P_{embedding} + P_{attention} + P_{mlp} + P_{output}$$

其中：

1. **Embedding 层**：
   $$P_{embedding} = vocab\_size \times n\_embd$$

2. **Attention 层**（每层）：
   $$P_{attention} = 4 \times n\_embd \times n\_embd$$
   
   详细分解：
   - Q, K, V 投影：$3 \times n\_embd \times n\_embd$
   - Output 投影：$1 \times n\_embd \times n\_embd$
   
   **使用 GQA 时**：
   $$P_{attention}^{GQA} = n\_embd \times (n\_embd + 2 \times n\_kv\_head \times head\_dim) + n\_embd \times n\_embd$$

3. **MLP 层**（每层）：
   $$P_{mlp} = 2 \times n\_embd \times (4 \times n\_embd) = 8 \times n\_embd^2$$
   
   详细分解：
   - Up projection: $n\_embd \times 4 \times n\_embd$
   - Down projection: $4 \times n\_embd \times n\_embd$

4. **Output 层**：
   $$P_{output} = n\_embd \times vocab\_size$$
   
   **注意**：如果与 embedding 共享权重，则 $P_{output} = 0$

**总参数量**：
$$P_{total} = vocab\_size \times n\_embd + n\_layer \times (12 \times n\_embd^2) + vocab\_size \times n\_embd$$

**简化公式**（不共享权重）：
$$P_{total} \approx 2 \times vocab\_size \times n\_embd + 12 \times n\_layer \times n\_embd^2$$

#### 实际计算示例

**GPT-2 Small (124M 参数)**：
- vocab_size = 50257
- n_embd = 768
- n_layer = 12
- n_head = 12

计算：
```
P_embedding = 50257 × 768 ≈ 38.6M
P_attention = 12 × 4 × 768² ≈ 28.3M
P_mlp = 12 × 8 × 768² ≈ 56.6M
P_output = 768 × 50257 ≈ 38.6M

P_total ≈ 38.6 + 28.3 + 56.6 + 38.6 ≈ 162.1M
```

实际参数量是 124M，说明使用了权重共享。

### 2.2 RoPE (Rotary Position Embedding) 数学推导

#### 核心思想

RoPE 通过**旋转操作**为每个位置添加位置信息，而不是使用传统的绝对位置编码。

#### 数学推导

**1. 二维旋转矩阵**

在二维平面中，旋转角度 $\theta$ 的旋转矩阵为：
$$R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$$

**2. 复数表示**

使用复数表示，旋转操作可以写成：
$$f(x, \theta) = x \cdot e^{i\theta}$$

其中 $x$ 是复数表示的特征向量。

**3. 扩展到高维**

对于 $d$ 维向量，将其分成 $d/2$ 对，每对应用二维旋转：
$$\begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \\ \vdots \\ x_{d-1} \\ x_d \end{bmatrix} \rightarrow \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} \otimes R(\theta_1), \begin{bmatrix} x_3 \\ x_4 \end{bmatrix} \otimes R(\theta_2), \ldots$$

**4. 旋转频率**

每个维度对的旋转频率不同：
$$\theta_k = m \cdot \omega_k$$

其中：
- $m$ 是位置索引
- $\omega_k = \frac{1}{10000^{2k/d}}$ 是第 $k$ 对的频率

**5. 完整公式**

对于位置 $m$ 的向量 $x$，RoPE 编码为：
$$RoPE(x, m) = \begin{bmatrix} x_1 \cos(m\omega_1) - x_2 \sin(m\omega_1) \\ x_1 \sin(m\omega_1) + x_2 \cos(m\omega_1) \\ x_3 \cos(m\omega_2) - x_4 \sin(m\omega_2) \\ x_3 \sin(m\omega_2) + x_4 \cos(m\omega_2) \\ \vdots \end{bmatrix}$$

#### PyTorch 实现

```python
import torch
import torch.nn as nn
import math

class RotaryPositionalEmbedding(nn.Module):
    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        self.dim = dim
        self.max_seq_len = max_seq_len
        self.base = base
        
        # 预计算旋转频率
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer('inv_freq', inv_freq)
        
        # 预计算 cos 和 sin
        self._build_cache(max_seq_len)
    
    def _build_cache(self, seq_len):
        """预计算所有位置的 cos 和 sin"""
        t = torch.arange(seq_len, dtype=self.inv_freq.dtype)
        freqs = torch.einsum('i,j->ij', t, self.inv_freq)
        
        # 复制以匹配维度
        emb = torch.cat((freqs, freqs), dim=-1)
        
        self.register_buffer('cos_cached', emb.cos())
        self.register_buffer('sin_cached', emb.sin())
    
    def forward(self, x, seq_len=None):
        """应用 RoPE
        
        Args:
            x: (batch, seq_len, n_head, head_dim)
            seq_len: 序列长度（可选，用于 KV Cache）
        
        Returns:
            应用 RoPE 后的张量
        """
        if seq_len is None:
            seq_len = x.shape[1]
        
        # 获取对应位置的 cos 和 sin
        cos = self.cos_cached[:seq_len]
        sin = self.sin_cached[:seq_len]
        
        # 应用旋转
        return self._apply_rotary_emb(x, cos, sin)
    
    def _apply_rotary_emb(self, x, cos, sin):
        """应用旋转嵌入"""
        # x: (batch, seq_len, n_head, head_dim)
        # cos, sin: (seq_len, head_dim)
        
        # 分割为两半
        x1 = x[..., :x.shape[-1]//2]
        x2 = x[..., x.shape[-1]//2:]
        
        # 应用旋转
        # 注意：这里使用的是顺时针旋转，与标准逆时针旋转等价
        y1 = x1 * cos[..., :x.shape[-1]//2] + x2 * sin[..., :x.shape[-1]//2]
        y2 = x1 * (-sin[..., :x.shape[-1]//2]) + x2 * cos[..., :x.shape[-1]//2]
        
        # 拼接
        return torch.cat([y1, y2], dim=-1)


# 使用示例
def test_rope():
    batch_size = 2
    seq_len = 10
    n_head = 8
    head_dim = 64
    
    # 创建 RoPE
    rope = RotaryPositionalEmbedding(head_dim)
    
    # 创建测试输入
    x = torch.randn(batch_size, seq_len, n_head, head_dim)
    
    # 应用 RoPE
    x_rope = rope(x)
    
    print(f"Input shape: {x.shape}")
    print(f"Output shape: {x_rope.shape}")
    
    # 验证维度
    assert x.shape == x_rope.shape, "Shape mismatch!"
    
    # 验证不同位置的编码不同
    pos_0 = rope(torch.randn(1, 1, n_head, head_dim), seq_len=1)
    pos_1 = rope(torch.randn(1, 1, n_head, head_dim), seq_len=1)
    
    # 注意：这里应该用相同的输入，不同的位置
    same_input = torch.randn(1, 2, n_head, head_dim)
    output = rope(same_input)
    
    print(f"Position 0 encoding: {output[0, 0, 0, :5]}")
    print(f"Position 1 encoding: {output[0, 1, 0, :5]}")
    print(f"Encodings are different: {not torch.allclose(output[0, 0], output[0, 1])}")

test_rope()
```

#### RoPE 的相对位置特性

**关键性质**：RoPE 编码的是相对位置，而不是绝对位置。

**数学证明**：

对于位置 $m$ 和 $n$ 的 query 和 key：
$$q_m^T k_n = (R_m q)^T (R_n k) = q^T R_m^T R_n k = q^T R_{n-m} k$$

其中 $R_{n-m}$ 是相对位置 $(n-m)$ 的旋转矩阵。

**这意味着**：
- 注意力分数只依赖于相对位置 $(n-m)$
- 具有平移不变性
- 更好的外推性

### 2.3 RMSNorm vs LayerNorm 数学对比

#### LayerNorm

**公式**：
$$LayerNorm(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

其中：
- $\mu = \frac{1}{d}\sum_{i=1}^{d} x_i$ 是均值
- $\sigma^2 = \frac{1}{d}\sum_{i=1}^{d} (x_i - \mu)^2$ 是方差
- $\gamma, \beta$ 是可学习参数

#### RMSNorm

**公式**：
$$RMSNorm(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2 + \epsilon}} \cdot \gamma$$

其中：
- $RMS(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2}$ 是均方根
- $\gamma$ 是可学习参数
- **没有均值计算和偏移参数 $\beta$**

#### 对比分析

| 维度 | LayerNorm | RMSNorm |
|------|-----------|---------|
| **计算复杂度** | O(d) | O(d) |
| **计算量** | 高（需要计算均值和方差） | 低（只需计算 RMS） |
| **参数量** | 2d ($\gamma$ 和 $\beta$) | d (只有 $\gamma$) |
| **数值稳定性** | 好 | 更好 |
| **对输入偏移的敏感性** | 敏感 | 不敏感 |
| **训练速度** | 慢 | 快 |

#### PyTorch 实现对比

```python
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    """标准 LayerNorm 实现"""
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(dim))
        self.beta = nn.Parameter(torch.zeros(dim))
        self.eps = eps
    
    def forward(self, x):
        # x: (batch, seq_len, dim)
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        
        # 归一化
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        
        # 缩放和平移
        return self.gamma * x_norm + self.beta


class RMSNorm(nn.Module):
    """RMSNorm 实现"""
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(dim))
        self.eps = eps
    
    def forward(self, x):
        # x: (batch, seq_len, dim)
        
        # 计算 RMS
        rms = torch.sqrt(torch.mean(x ** 2, dim=-1, keepdim=True) + self.eps)
        
        # 归一化
        x_norm = x / rms
        
        # 缩放（无平移）
        return self.gamma * x_norm


def test_normalization():
    batch_size = 2
    seq_len = 10
    dim = 64
    
    # 创建测试输入

    # LayerNorm

    # RMSNorm

    y_rn = rn(x)
    
    print(f"Input shape: {x.shape}")
    print(f"LayerNorm output shape: {y_ln.shape}")
    print(f"RMSNorm output shape: {y_rn.shape}")
    
    # 验证数值稳定性
    print(f"\nLayerNorm mean: {y_ln.mean(dim=-1)[0, 0]:.6f}")
    print(f"LayerNorm std: {y_ln.std(dim=-1)[0, 0]:.6f}")
    print(f"RMSNorm mean: {y_rn.mean(dim=-1)[0, 0]:.6f}")
    print(f"RMSNorm std: {y_rn.std(dim=-1)[0, 0]:.6f}")
    
    # 性能测试

    # LayerNorm 性能
    start = time.time()
    for _ in range(1000):
        _ = ln(x)
    ln_time = time.time() - start

    for _ in range(1000):
        _ = rn(x)

    print(f"RMSNorm time: {rn_time:.4f}s")
    print(f"Speedup: {ln_time / rn_time:.2f}x")

test_normalization()
```

#### 为什么 RMSNorm 更稳定？

**数值稳定性分析**：

1. **避免均值计算**：
   - LayerNorm 需要计算 $\mu = \frac{1}{d}\sum x_i$
   - 当输入有偏移时，$\mu$ 可能很大，导致数值不稳定
   - RMSNorm 直接计算 RMS，不受偏移影响

2. **梯度稳定性**：
   - LayerNorm 的梯度涉及均值和方差的梯度
   - RMSNorm 的梯度更简单，数值更稳定

3. **实验验证**：

## 3. 注意力机制详解

### 3.1 标准 Self-Attention

#### 数学公式

**Query, Key, Value 计算**：
$$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$$

**注意力分数**：
$$Attention(Q, K, V) = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

**维度变换**：
- 输入 $X$: $(B, T, D)$
- $W_Q, W_K, W_V$: $(D, D)$
- $Q, K, V$: $(B, T, D)$
- 注意力分数: $(B, T, T)$
- 输出: $(B, T, D)$

#### PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class StandardSelfAttention(nn.Module):
    def __init__(self, n_embd, n_head):
        super().__init__()
        assert n_embd % n_head == 0
        
        self.n_head = n_head
        self.head_dim = n_embd // n_head
        
        # Q, K, V 投影
        self.c_q = nn.Linear(n_embd, n_embd, bias=False)
        self.c_k = nn.Linear(n_embd, n_embd, bias=False)
        self.c_v = nn.Linear(n_embd, n_embd, bias=False)
        
        # Output 投影
        self.c_proj = nn.Linear(n_embd, n_embd, bias=False)
    
    def forward(self, x):
        B, T, D = x.shape
        
        # 计算 Q, K, V
        q = self.c_q(x)  # (B, T, D)
        k = self.c_k(x)  # (B, T, D)
        v = self.c_v(x)  # (B, T, D)
        
        # 重塑为多头
        q = q.view(B, T, self.n_head, self.head_dim).transpose(1, 2)  # (B, n_head, T, head_dim)
        k = k.view(B, T, self.n_head, self.head_dim).transpose(1, 2)  # (B, n_head, T, head_dim)
        v = v.view(B, T, self.n_head, self.head_dim).transpose(1, 2)  # (B, n_head, T, head_dim)
        
        # 计算注意力分数
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(self.head_dim))  # (B, n_head, T, T)
        
        # Causal mask
        mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=x.device), diagonal=1)
        att = att.masked_fill(mask, float('-inf'))
        
        # Softmax
        att = F.softmax(att, dim=-1)
        
        # 应用注意力到 V
        y = att @ v  # (B, n_head, T, head_dim)
        
        # 重塑回原始维度
        y = y.transpose(1, 2).contiguous().view(B, T, D)  # (B, T, D)
        
        # Output 投影
        y = self.c_proj(y)
        
        return y
```

### 3.2 Group-Query Attention (GQA)

#### 核心思想

GQA 是 Multi-Query Attention (MQA) 和 Multi-Head Attention (MHA) 的折中：
- **MHA**：每个 head 都有独立的 K, V
- **MQA**：所有 head 共享一组 K, V
- **GQA**：将 head 分组，每组共享一组 K, V

#### 数学公式

**Query 计算**（与标准注意力相同）：
$$Q = XW_Q, \quad Q \in \mathbb{R}^{B \times T \times n\_head \times head\_dim}$$

**Key, Value 计算**（分组）：
$$K = XW_K, \quad K \in \mathbb{R}^{B \times T \times n\_kv\_head \times head\_dim}$$
$$V = XW_V, \quad V \in \mathbb{R}^{B \times T \times n\_kv\_head \times head\_dim}$$

**Key, Value 扩展**：
$$K_{expanded} = repeat(K, n\_head // n\_kv\_head)$$
$$V_{expanded} = repeat(V, n\_head // n\_kv\_head)$$

#### PyTorch 实现

```python
class GroupedQueryAttention(nn.Module):
    def __init__(self, n_embd, n_head, n_kv_head):
        super().__init__()
        assert n_embd % n_head == 0
        assert n_head % n_kv_head == 0
        
        self.n_head = n_head
        self.n_kv_head = n_kv_head
        self.head_dim = n_embd // n_head
        self.n_rep = n_head // n_kv_head  # 每个 KV head 对应的 query head 数
        
        # Q 投影（完整）
        self.c_q = nn.Linear(n_embd, n_embd, bias=False)
        
        # K, V 投影（减少）
        self.c_k = nn.Linear(n_embd, self.n_kv_head * self.head_dim, bias=False)
        self.c_v = nn.Linear(n_embd, self.n_kv_head * self.head_dim, bias=False)
        
        # Output 投影
        self.c_proj = nn.Linear(n_embd, n_embd, bias=False)
    
    def forward(self, x):
        B, T, D = x.shape
        
        # 计算 Q
        q = self.c_q(x)  # (B, T, n_head * head_dim)
        q = q.view(B, T, self.n_head, self.head_dim).transpose(1, 2)  # (B, n_head, T, head_dim)
        
        # 计算 K, V
        k = self.c_k(x)  # (B, T, n_kv_head * head_dim)
        k = k.view(B, T, self.n_kv_head, self.head_dim).transpose(1, 2)  # (B, n_kv_head, T, head_dim)
        
        v = self.c_v(x)  # (B, T, n_kv_head * head_dim)
        v = v.view(B, T, self.n_kv_head, self.head_dim).transpose(1, 2)  # (B, n_kv_head, T, head_dim)
        
        # 扩展 K, V
        k = self._repeat_kv(k)  # (B, n_head, T, head_dim)
        v = self._repeat_kv(v)  # (B, n_head, T, head_dim)
        
        # 计算注意力（与标准注意力相同）
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(self.head_dim))
        
        # Causal mask
        mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=x.device), diagonal=1)
        att = att.masked_fill(mask, float('-inf'))
        att = F.softmax(att, dim=-1)
        
        # 应用注意力
        y = att @ v
        
        # 重塑
        y = y.transpose(1, 2).contiguous().view(B, T, D)
        y = self.c_proj(y)
        
        return y
    
    def _repeat_kv(self, x):
        """扩展 K, V 以匹配 query head 数
        
        Args:
            x: (B, n_kv_head, T, head_dim)
        
        Returns:
            (B, n_head, T, head_dim)
        """
        B, n_kv_head, T, head_dim = x.shape
        
        if self.n_rep == 1:
            return x
        
        # 扩展维度
        x = x.unsqueeze(2)  # (B, n_kv_head, 1, T, head_dim)
        x = x.expand(B, n_kv_head, self.n_rep, T, head_dim)  # (B, n_kv_head, n_rep, T, head_dim)
        x = x.reshape(B, self.n_head, T, head_dim)  # (B, n_head, T, head_dim)
        
        return x
```

#### KV Cache 显存节省计算

**标准注意力（MHA）**：
$$KV\_Cache_{MHA} = 2 \times B \times T \times n\_head \times head\_dim \times 2 \text{ bytes}$$

**GQA**：
$$KV\_Cache_{GQA} = 2 \times B \times T \times n\_kv\_head \times head\_dim \times 2 \text{ bytes}$$

**节省比例**：
$$\frac{KV\_Cache_{GQA}}{KV\_Cache_{MHA}} = \frac{n\_kv\_head}{n\_head}$$

**示例**（LLaMA-2 70B）：
- n_head = 64
- n_kv_head = 8
- 节省比例 = 8/64 = 1/8 = 87.5%

### 3.3 滑动窗口注意力

#### 核心思想

限制每个 token 只能关注固定窗口内的 token，减少计算复杂度。

#### 数学公式

**标准注意力复杂度**：$O(T^2 \cdot D)$

**滑动窗口注意力复杂度**：$O(T \cdot W \cdot D)$，其中 $W$ 是窗口大小

**注意力 mask**：
$$M_{ij} = \begin{cases} 0 & \text{if } i - W \leq j \leq i \\ -\infty & \text{otherwise} \end{cases}$$

#### PyTorch 实现

```python
class SlidingWindowAttention(nn.Module):
    def __init__(self, n_embd, n_head, window_size):
        super().__init__()
        self.n_head = n_head
        self.head_dim = n_embd // n_head
        self.window_size = window_size
        
        self.c_q = nn.Linear(n_embd, n_embd, bias=False)
        self.c_k = nn.Linear(n_embd, n_embd, bias=False)
        self.c_v = nn.Linear(n_embd, n_embd, bias=False)
        self.c_proj = nn.Linear(n_embd, n_embd, bias=False)
    
    def forward(self, x):
        B, T, D = x.shape
        
        # 计算 Q, K, V
        q = self.c_q(x).view(B, T, self.n_head, self.head_dim).transpose(1, 2)
        k = self.c_k(x).view(B, T, self.n_head, self.head_dim).transpose(1, 2)
        v = self.c_v(x).view(B, T, self.n_head, self.head_dim).transpose(1, 2)
        
        # 计算注意力分数
        att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(self.head_dim))
        
        # 创建滑动窗口 mask
        mask = self._create_sliding_window_mask(T, x.device)
        att = att.masked_fill(mask, float('-inf'))
        
        # Softmax
        att = F.softmax(att, dim=-1)
        
        # 应用注意力
        y = att @ v
        y = y.transpose(1, 2).contiguous().view(B, T, D)
        y = self.c_proj(y)
        
        return y
    
    def _create_sliding_window_mask(self, T, device):
        """创建滑动窗口 mask
        
        Args:
            T: 序列长度
            device: 设备
        
        Returns:
            mask: (T, T), True 表示要 mask 的位置
        """
        # 创建因果 mask
        causal_mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=device), diagonal=1)
        
        # 创建滑动窗口 mask
        window_mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=device), diagonal=self.window_size + 1)
        
        # 组合两个 mask
        mask = causal_mask | window_mask
        
        return mask
```

## 4. 归一化与激活函数

### 4.1 SwiGLU 激活函数

#### 数学公式

**标准 SwiGLU**：
$$SwiGLU(x) = Swish(xW_1 + b_1) \otimes (xV_1 + c_1)$$

其中：
- $Swish(x) = x \cdot \sigma(x)$
- $\sigma(x) = \frac{1}{1 + e^{-x}}$ 是 sigmoid 函数
- $\otimes$ 是逐元素乘法

**NanoChat 的简化版本（ReLU²）**：
$$ReLU^2(x) = (\max(0, x))^2$$

#### PyTorch 实现

```python
class SwiGLU(nn.Module):
    """标准 SwiGLU 实现"""
    def __init__(self, n_embd, hidden_dim=None):
        super().__init__()
        if hidden_dim is None:
            hidden_dim = 4 * n_embd
        
        self.w1 = nn.Linear(n_embd, hidden_dim, bias=False)
        self.v1 = nn.Linear(n_embd, hidden_dim, bias=False)
        self.w2 = nn.Linear(hidden_dim, n_embd, bias=False)
    
    def forward(self, x):
        # Swish(xW1) ⊗ (xV1)
        gate = F.silu(self.w1(x))  # SiLU = Swish
        value = self.v1(x)
        x = gate * value
        
        # 输出投影
        x = self.w2(x)
        return x


class ReLUSquared(nn.Module):
    """NanoChat 的简化版本"""
    def __init__(self, n_embd):
        super().__init__()
        self.c_fc = nn.Linear(n_embd, 4 * n_embd, bias=False)
        self.c_proj = nn.Linear(4 * n_embd, n_embd, bias=False)
    
    def forward(self, x):
        x = self.c_fc(x)
        x = F.relu(x).square()  # ReLU²
        x = self.c_proj(x)
        return x
```

## 5. 面试拷问预演

### Q1: "为什么 Transformer 使用 LayerNorm 而不是 BatchNorm？"

**标准答案**：
1. **序列长度可变**：BatchNorm 需要固定的 batch 统计量，而 Transformer 输入序列长度可变
2. **训练推理不一致**：BatchNorm 在训练和推理时行为不同（使用 batch 统计量 vs 运行统计量）
3. **小 batch size 问题**：Transformer 训练时 batch size 可能很小，BatchNorm 统计量不稳定
4. **位置独立性**：LayerNorm 对每个位置独立归一化，保持了位置间的独立性

**进阶答案**：
- LayerNorm 更适合处理变长序列
- LayerNorm 在训练和推理时行为一致
- LayerNorm 不受 batch size 影响
- 实验证明 LayerNorm 在 Transformer 中效果更好

### Q2: "RoPE 相比传统位置编码有什么优势？"

**标准答案**：
1. **相对位置编码**：编码的是相对位置，而不是绝对位置
2. **外推性更好**：可以处理比训练时更长的序列
3. **无额外参数**：不需要可学习的位置编码参数
4. **计算高效**：通过旋转操作实现，计算简单

**进阶答案**：
- **数学原理**：RoPE 通过旋转操作实现相对位置编码
- **外推性问题**：虽然 RoPE 外推性比绝对位置编码好，但仍有局限性
- **解决方案**：线性缩放、NTK-Aware Scaling、LongRoPE 等
- **实现细节**：需要预计算 cos 和 sin，支持 KV Cache

### Q3: "GQA 相比 MHA 和 MQA 的权衡是什么？"

**标准答案**：
1. **MHA**：质量最高，但 KV Cache 显存占用最大
2. **MQA**：KV Cache 显存占用最小，但质量有损失
3. **GQA**：质量和显存占用的平衡

**进阶答案**：
- **质量对比**：MHA > GQA > MQA
- **显存对比**：MHA > GQA > MQA
- **计算复杂度**：GQA 与 MHA 相同（因为 Q 的数量相同）
- **实际应用**：LLaMA-2 使用 GQA（n_head=64, n_kv_head=8）

### Q4: "滑动窗口注意力的窗口大小如何选择？"

**标准答案**：
1. **任务需求**：对话任务窗口可以较小，文档任务需要较大窗口
2. **硬件限制**：窗口大小影响显存占用
3. **实验验证**：通过 ablation study 确定最优窗口大小

**进阶答案**：
- **多层混合**：浅层用小窗口，深层用大窗口
- **动态窗口**：根据输入长度动态调整窗口大小
- **与 RoPE 结合**：滑动窗口可以缓解 RoPE 的外推性问题
- **实际应用**：Mistral 使用滑动窗口注意力（window_size=4096）

### Q5: "如果让你改进 NanoChat 的架构，你会怎么做？"

**标准答案**：
1. **添加 PagedAttention**：更高效的 KV Cache 管理
2. **实现 Continuous Batching**：提升推理吞吐量
3. **添加模型量化**：支持 INT4/INT8 推理
4. **优化数据加载**：更高效的数据预处理

**进阶答案**：
- **架构改进**：
  - 使用 GQA（当前是 MHA）
  - 添加滑动窗口注意力（已支持）
  - 使用更先进的激活函数（如 GeGLU）
  
- **训练改进**：
  - 添加更好的学习率调度（如 Cosine with Warmup）
  - 实现更稳定的梯度裁剪策略
  - 添加训练稳定性监控
  
- **推理改进**：
  - 实现 PagedAttention
  - 添加 KV Cache 量化
  - 支持分布式推理（Tensor Parallelism）
